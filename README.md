# CraftCode Studio — Neon Blue Edition

Run the project:
1. unzip
2. npm install
3. npm run dev
4. open http://localhost:5173

Notes:
- Theme uses neon-blue as primary accent.
- Buttons have hover sound via WebAudio (no external file).
- Particles are powered by react-tsparticles.
- Contact form is visual only (demo) — integrate a backend or Formspree for real messages.
- Email used on site: hello@craftcodestudio.com
